# JavaScript To-Do List

A responsive and interactive To-Do List application built using HTML, CSS, and JavaScript.

## 🌐 Live Demo

👉 **[Open Live Demo](https://hiranmaikuna.github.io/javascript-todo-list//)**

## 📌 Project Description

This project is a client-side To-Do List application developed to demonstrate JavaScript logic, DOM manipulation, event handling, CRUD operations, filtering, and local data persistence.

Users can add, edit, complete, delete, and filter tasks. Tasks are stored automatically using browser `localStorage`.

## ✨ Features

- ➕ Add new tasks
- ✏️ Edit tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 🔎 Filter tasks by All, Active, and Completed
- 💾 Persistent data using localStorage
- 📱 Responsive design
- ⚡ Dynamic DOM manipulation
- 🖱️ Event delegation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- LocalStorage
